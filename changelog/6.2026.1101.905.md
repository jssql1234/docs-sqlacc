POS improvements, reporting enhancements, and various bug fixes. (*905*)

<!-- truncate -->

## Updates

- **SQL POS**:
  - Tidied POS projects structure.
  - Removed DBManager code from POS.BO.Impl.pas.
  - Fixed MnM_Rule_ItemCode DoChange IBO functionality.
  - Added export for serial number table.
  - Added copy-to-clipboard action for overview in more button.
  - Fixed terminal unable to delete if metadata was never synced before.
  - Refactored promotion query to multi-line SQL for better performance.
  - Added POS module filter in AuditTrail.

- **Reports**:
  - Outstanding Job Order report no longer shows master record when there are no detail items or when filtering detail items (#8068).
  - Stock Analysis By Document report now shows Balance Amount as 0 when Balance Qty is 0 or less (#8065).
  - GL Project Profit & Loss with Cash Flow report detail grid now includes Account Description column (#8073).
  - GL Ledger report now offers "All Ledger" option (Feature #7978).
  - Stock Reorder Advice Report now correctly displays Reorder Level, Reorder Qty, and Min/Max Qty (#8024).
  - GL BS - 6C1P now correctly shows FA Acquire Amount when Fixed Asset doesn't have depreciation account.
  - Yearly Sales Analysis and Sales Analysis by Document now correctly filter by selected Category when "Include Zero balance" option is ticked (#8051).

- **Clipboard Import**:
  - Renamed template IRBM_Status to TA_Status and IRBM_UUID to TA_UUID.

- **E-Commerce**:
  - Added TikTok shop commission fee, voucher extra service fee, and GMV max fee when editing sales credit note.

- **E-Invoice (MyInvois)**:
  - Improved E-Invoice size limit checking performance.
  - Revised GetDocumentDetails to use TypeVersionNumber.

- **Peppol (SG)**:
  - Fixed field access violation when document does not have the TA_Status field.

- **General**:
  - Disabled control of datasets to improve DBAccess cancel performance.
  - Revised TAppSession.AccessRightItems to prevent access violation when session setup without access rights.
  - Post customer invoice if past sales invoices don't require any editing.
  - Revised Peppol export and import constructors to accept IDBConnection.
  - Revised TUNECE_UOMProvider method to accept IDBConnection.
  - Fixed Get Document Types JSON response datatype.

## Bug Fixes

- **Stock**:
  - Fixed Stock Adjustment Reason field underline misplacement (#8063).
  - Fixed Dynamic SQL Error when ticking "Exclude Stock Transfer Date (use Ref Cost)" option and filtering Location lookup in Stock Aging report (#8062).

- **Clipboard Import**:
  - Fixed default tax code being applied on empty tax cell (#8060).

- **Mobile Connect**:
  - Fixed incorrect batch item lookup (#8019).

- **Stock Matrix**:
  - Document entry forms' Stock Matrix Profile lookup now allows resizing (#8046).
