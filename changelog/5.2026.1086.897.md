Fixed Assets useful life improvement, TikTok return shipping fee support, MyInvois fixes, and various bug fixes. (*897*)

<!-- truncate -->

## Updates

- **Fixed Assets**:
  - Separated Asset Item Useful Life (Years) field into Years and Months (#7903).

- **General Ledger (GL)**:
  - Revised icon in Maintain Account.
  - Added TBankCatalog.

- **E-Commerce**:
  - Included TikTok actual return shipping fee in sales invoice for orders with positive settlement amount.
  - Adjusted TikTok sales credit note editing.

## Bug Fixes

- **General Ledger (GL)**:
  - Fixed Bank Balance label not refreshing after save/delete document in GL Cash Book, AR/AP Payment & Refund (#7945).
  - Fixed GL Balance Sheet (6C1P) Fixed Assets spelling error.
  - Fixed GL Balance Sheet (6C1P) Fixed Assets grand total calculation.

- **Sales / Purchase**:
  - Fixed default currency rate not set to 1 when copying documents to a target database with an invalid currency code (#7842).
  - Fixed item code description duplication when item code is empty.
  - Fixed Sales Invoice 11 layout with some fields too small.

- **MyInvois (E-Invoice MY)**:
  - Fixed Sales/Purchase new records not refreshing the difference indicator.

- **E-Commerce**:
  - Fixed Shopee fees posting in sales credit note for non-return orders.
